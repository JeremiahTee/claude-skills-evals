# wrap (example fixture)

An invented example skill, shipped so the trigger evals have something to route to.

1. List what was done this session and what is still pending.
2. Finish small pending tasks; list the rest.
3. Save any notes or memory updates the user approved.
4. Say which closer applies next: handoff, extract-learnings, or none.
